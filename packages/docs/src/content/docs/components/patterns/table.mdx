The pure data grid: columns, cells and sortable headers with `aria-sort`. It's
controlled — sorting is reported via `onSortToggle`; for the batteries-included
shell (config, views, pagination) see [TableSet](/invisible-ui/components/patterns/table-set/).

### Import

<ImportSnippet component="table" />

### Props

<PropsTable component="table" />

Use the `cell` slot (`let:row let:column let:value let:rowIndex`) for custom
cell rendering.

### Row selection column

With `selectionColumn`, the table renders a structural first column and two
scoped slots to fill it: `selectionHeader` for the `<th>` (the select-all
control lives here) and `selectionCell` (`let:row let:rowId let:rowIndex`) for
each row's control. The table itself holds no selection state: pair the slots
with your own state or use
[Table Set](/invisible-ui/components/patterns/table-set/), which wires
controlled row selection on top of this column — see its
[Row selection](/invisible-ui/components/patterns/table-set/#row-selection)
section. `isRowSelected` only paints `data-selected` on the row for styling.

### Accessibility

- A real `<table>` with `<caption>`; sortable headers expose `aria-sort`.

### Example

```svelte
<Table caption="Team" columns={[{ key: "name", header: "Name", sortable: true }]} rows={rows} />
```

In Elements, structured data is assigned through properties. The component
reports a requested sort and leaves row ordering to the application:

```html
<ds-table caption="Team"></ds-table>

<script type="module">
  const table = document.querySelector("ds-table");
  table.columns = [
    { key: "name", header: "Name", sortable: true },
    { key: "role", header: "Role" },
  ];
  table.rows = people;
  table.addEventListener("sort-toggle", ({ detail }) => {
    table.sort = nextSort(table.sort, detail.key);
    table.rows = sortPeople(people, table.sort);
  });
</script>
```

Themeable via `--ds-table-*`. The header stays transparent by default. Set
`--ds-table-header-background` on the table or an ancestor when the header
needs its own fill; this component token does not create a new global surface
role.
