A sign-in organism composed from the primitives: an optional logo, social-login
buttons, the email + password fields, a "forgot password" link, and the submit
button. It is a real `<form>` — `onSubmit` receives `{ email, password }`.

### Import

<ImportSnippet component="login-form" />

In Elements, the form reports a cancelable `submit` event. With `action`, it
also submits natively to that URL:

```html
<ds-login-form action="/session" method="post">
  <img slot="logo" src="/logo.svg" alt="Acme" />
</ds-login-form>

<script type="module">
  const login = document.querySelector("ds-login-form");
  login.providers = [{ id: "google", label: "Google" }];
  login.addEventListener("provider", (event) => signInWith(event.detail.id));
</script>
```

### Props

<PropsTable component="login-form" />

Pass a logo via the `logo` slot and provider glyphs via `provider-icon`.

### Example

```svelte
<LoginForm
  providers={[{ id: "google", label: "Google" }]}
  onSubmit={({ email, password }) => signIn(email, password)}
/>
```

Themeable via `--ds-login-*`.
