A form-field wrapper that links a label, optional description and error message
to a control, wiring `aria-describedby` / `aria-invalid` for you.

### Import

<ImportSnippet component="field" />

### Props

<PropsTable component="field" />

In Svelte, the control is the `children` snippet, which receives `controlProps` and `controlId`:

```svelte
<Field label="Email">
  {#snippet children({ controlProps })}
    <input {...controlProps} type="email" />
  {/snippet}
</Field>
```

In React, `children` is a function that receives `controlProps` and
`controlId`, and `useField` wires markup of your own:

```tsx
<Field label="Email" error={error}>
  {({ controlProps }) => <input {...controlProps} type="email" />}
</Field>
```

Themeable via `--ds-field-*`.
