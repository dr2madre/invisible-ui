The styled, batteries-included button, carrying a semantic `variant` (what the
action means, not a style): `default`, `primary`, `secondary`, `danger`,
`ghost`.

Two presets have their own pages:
[Icon Button](/invisible-ui/components/forms/icon-button/) (square, icon-only)
and [Loading Button](/invisible-ui/components/forms/loading-button/)
(in-flight state with announcements).

### Accessibility

- Every button needs an accessible name: visible text (default slot) or `ariaLabel` for icon-only buttons.
- `danger` shows a hazard icon by default, so meaning never relies on color alone (WCAG 1.4.1).
- Behaviour and a11y (focus, Enter/Space activation) come from the headless button.

### Copy confirmation

In Elements and React, `copy` holds text for the button to copy. After a successful
copy, "Copied" (or `copied-label`, `copiedLabel` in React) shows beside the button for two seconds,
announced through a polite live region; the button keeps its name and focus.
It is the confirmation at the source that
[ADR 0016](https://github.com/dr2madre/invisible-ui/blob/main/docs/adr/0016-feedback-while-a-dialog-is-open.md)
asks for inside a dialog.

```html
<ds-button copy="https://example.com/reports/q3" copied-label="Link copied">Copy the link</ds-button>
```

In Vue, the same props are `copy` and `copiedLabel`:

```vue
<Button copy="https://example.com/reports/q3" copied-label="Link copied">Copy the link</Button>
```

In React, the props are `copy` and `copiedLabel`:

```tsx
<Button copy="https://example.com/reports/q3" copiedLabel="Link copied">
  Copy the link
</Button>
```

### Example

```svelte
<Button variant="primary" onpress={() => save()}>Save changes</Button>
```

Themeable via `--ds-button-*`.
