A star rating built on native `<input type="radio">` stars — single-select with
browser-provided roving tabindex, arrow keys and form participation.

### Import

<ImportSnippet component="rating-group" />

In Elements, the stars take their names from the locale catalog. Choosing a
star sends a bubbling `change` event with the rating as a number in
`detail.value`:

```html
<ds-rating-group label="Rating" name="rating" value="4"></ds-rating-group>
```

### Error message

<Preview>
  <RatingGroupErrorDemo client:visible />
</Preview>

A non-empty `error` shows the message under the control with a hazard icon and
announces it as an alert. Every star points at it through `aria-describedby`.
Neither the stars nor the radio group takes `aria-invalid`. The message is plain
text.

```svelte
<RatingGroup label="Rating" bind:value error={value === null ? "Choose a rating." : ""} />
```

The app owns the message and clears it: a form reset leaves it in place.
In Flutter, the validator's message clears on form reset.

### Accessibility

- A labelled `role="radiogroup"` of native radio stars; the browser handles
  arrow-key move/select and form submission.
- A non-empty `error` links every star to the message through
  `aria-describedby`.

### Example

```svelte
<RatingGroup value={3} max={5} label="Rating" />
```

In React, `onValueChange` reports the rating as a number:

```tsx
<RatingGroup label="Rating" value={rating} onValueChange={setRating} />
```

Themeable via `--ds-rating-*`.
