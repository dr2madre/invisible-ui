`SearchField` composes a native search input, a conditional clear button and a
submit button inside one visual control. Use it inside a native form. The submit
button keeps the form's normal submission behavior.

### Import

<ImportSnippet component="search-field" />

```svelte
<form role="search" on:submit={search}>
  <SearchField
    label="Search tables and columns"
    hideLabel
    name="query"
    bind:value={query}
  />
</form>
```

In Elements:

```html
<form role="search">
  <ds-search-field
    label="Search tables and columns"
    hide-label
    name="query"
  ></ds-search-field>
</form>
```

The clear button appears only when the field has a value. It reports an empty
value once and returns focus to the search input. `clearLabel` / `clear-label`
and `submitLabel` / `submit-label` override the localized accessible names.

The component provides its own clear button because browsers do not expose a
consistent native cancel affordance. It suppresses the browser-specific cancel
glyph only inside this component, avoiding duplicate controls in Chromium and
WebKit while keeping the same behavior in Firefox.

### Accessibility

- Keep the real label. `hideLabel` hides it only visually.
- The clear and submit icons are decorative; their buttons have accessible
  names.
- Keyboard order is input, clear when present, then submit.
- Enter in the input follows native form submission.
- Disabled and read-only search fields do not expose a clear action.
