An independent on/off control (e.g. Bold in a toolbar), built on a native
`<button type="button">` that carries `aria-pressed`.

### Import

<ImportSnippet component="toggle-button" />

In Elements, the children are the visible content. The pressed state is
reflected by the `pressed` attribute and reported through the bubbling `change`
event with `detail.pressed`:

```html
<ds-toggle-button label="Bold" name="bold">B</ds-toggle-button>
```

### Error message

<Preview>
  <ToggleButtonErrorDemo client:visible />
</Preview>

A non-empty `error` shows the message under the control with a hazard icon and
announces it as an alert. The button points at it through `aria-describedby`.
The button takes no `aria-invalid`. The message is plain text.

```svelte
<ToggleButton check bind:pressed error={pressed ? "" : "Turn on email updates to get the code."}>
  Email updates
</ToggleButton>
```

The app owns the message and clears it: a form reset leaves it in place.
In Flutter, the validator's message clears on form reset.

### Accessibility

- A native button with `aria-pressed`, following the
  [WAI-ARIA button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/):
  the browser owns the role and focus, and Enter and Space toggle it. Exposes
  `data-state="on" \| "off"` for styling.
- The accessible name never changes with the state: only the pressed state
  does. Keep the label the same ("Bold"), not "Bold on" and "Bold off".
- Provide `label` when the slot content is icon-only so the control still has an accessible name.
- Pass `name` (and optional `value`) to submit the pressed state with a form:
  while the button is pressed and enabled, a hidden input sends `value` under
  `name`, as a checked checkbox would. This form participation is provisional
  and may change.
- Distinct from `Switch`: a toggle button is an action, a switch is a setting.
- A non-empty `error` links the button to the message through
  `aria-describedby`.
- Assistive technology: not tested.

### Example

```svelte
<ToggleButton label="Bold" onPressedChange={(on) => setBold(on)}>B</ToggleButton>
```

In React, the content is `children`, and `onPressedChange` reports each
press:

```tsx
<ToggleButton label="Bold" pressed={bold} onPressedChange={setBold}>
  <BoldIcon />
</ToggleButton>
```

Themeable via `--ds-toggle-*`.
