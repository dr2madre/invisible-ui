A one-cell-per-character code input (OTP / PIN) with auto-advance, paste
spreading and backspace handling.

### Import

<ImportSnippet component="pin-input" />

In Elements:

```html
<ds-pin-input label="Verification code" name="code" length="6"></ds-pin-input>
```

The element sends `change` with `detail.value` on every edit and `complete`
once every cell is filled.

### Digits from other scripts

A numeric PIN input accepts Arabic-Indic (٠–٩) and Persian (۰–۹) digits,
typed or pasted, in every locale. The cells show ASCII digits, and
`onValueChange` and `onComplete` report ASCII digits.

### Error message

<Preview>
  <PinInputErrorDemo client:visible />
</Preview>

A non-empty `error` shows the message under the control with a hazard icon and
announces it as an alert. It also marks the cells invalid, as `invalid` does.
Every cell points at it through `aria-describedby` and takes
`aria-invalid="true"`; the group takes neither. The message is plain text.

```svelte
<PinInput label="Verification code" length={6} bind:value error={codeError} />
```

The app owns the message and clears it: a form reset leaves it in place.
In Flutter, the validator's message clears on form reset.

### Accessibility

- A labelled group of single-character inputs; focus auto-advances and paste
  fills across cells.
- The arrows follow the layout direction. In a right-to-left layout,
  ArrowLeft moves to the next cell and ArrowRight to the previous one.
- A non-empty `error` adds `aria-invalid="true"` and an `aria-describedby`
  link to the message on every cell.

### Example

```svelte
<PinInput length={4} label="Verification code" />
```

In React, `onComplete` reports the code once every cell is filled:

```tsx
<PinInput label="Verification code" length={6} name="code" onComplete={verify} />
```

Themeable via `--ds-pin-input-*`.
