A single-thumb slider built on a native `<input type="range">` — pointer drag,
keyboard control and form participation come from the browser.

### Import

<ImportSnippet component="slider" />

In Elements, the attributes set the value and the range. The `format`
property turns a number into the text the readouts show, and moving the thumb
sends a bubbling `change` event with `detail.value`:

```html
<ds-slider label="Volume" name="volume" value="40" step="10" show-value></ds-slider>
```

### Error message

<Preview>
  <SliderErrorDemo client:visible />
</Preview>

A non-empty `error` shows the message under the control with a hazard icon and
announces it as an alert. The input points at it through `aria-describedby` and
takes `aria-invalid="true"`. The message is plain text.

```svelte
<Slider label="Volume" bind:value error={value === 0 ? "Choose a volume above zero." : ""} />
```

The app owns the message and clears it: a form reset leaves it in place.
In Flutter, the validator's message clears on form reset.

### Accessibility

- Native `<input type="range">`: the browser provides the slider role, ARIA
  value, Arrow/Home/End/PageUp-Down control, pointer dragging and form
  submission.
- A non-empty `error` adds `aria-invalid="true"` and an `aria-describedby`
  link to the message on the input.

### Example

```svelte
<Slider value={40} step={5} label="Volume" />
```

In React, `onValueChange` reports each move, and the `icon` prop takes the
leading glyph:

```tsx
<Slider label="Volume" value={volume} showValue icon={<VolumeIcon />} onValueChange={setVolume} />
```

Themeable via `--ds-slider-*`.
