A date field that opens a [Calendar](/invisible-ui/components/forms/calendar/) in a popover. The
readonly combobox field is the trigger; picking a day fills the field and
closes the popover.

### Import

<ImportSnippet component="date-picker" />

In Elements, `name` submits the ISO date with the form:

```html
<form>
  <ds-date-picker label="Due date" name="due" value="2026-06-15" clearable></ds-date-picker>
</form>
```

### Accessibility

- The field is a readonly `role="combobox"` (`aria-haspopup`, `aria-expanded`):
  a click, Enter, Space or ArrowDown opens it. Focus moves to the selected day,
  or to the day the calendar would focus when none is selected, not to the
  Today button.
- Picking a day, or pressing Escape, closes the calendar and returns focus to
  the field. The clear button keeps focus on the field when it removes itself.
- See the [Calendar](/invisible-ui/components/forms/calendar/) for the grid's keyboard model.

### Example

```svelte
<DatePicker value="2026-06-15" label="Event date" clearable />
```

In React, `onValueChange` reports the picked date, or `null` when cleared:

```tsx
<DatePicker label="Event date" value={date} name="date" clearable onValueChange={setDate} />
```

Themeable via `--ds-date-picker-*` and the calendar's `--ds-calendar-*`.
