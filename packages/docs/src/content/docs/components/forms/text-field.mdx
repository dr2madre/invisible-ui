A styled single-line text field with label, optional description and error message.

### Native constraints

`maxlength`, `minlength`, `pattern`, `inputmode`, `autocomplete` and
`spellcheck` reach the real `<input>`, so the browser enforces and reports them
itself — a too-short value blocks submission with the platform's own message,
and a password manager or an SMS code can autofill.

```svelte
<TextField label="Postcode" maxlength={8} pattern="[A-Z0-9 ]+" autocomplete="postal-code" />
```

For numeric entry use the
[Number Field](/invisible-ui/components/forms/number-field/): it parses the
user's locale and keeps the typed draft, which `type="number"` cannot do.

### Accessibility

- Label association plus `aria-describedby` (hint and error), `aria-invalid`, `aria-required` come from the headless text field.
- A non-empty `error` puts the field in the invalid state and announces the message.

### Example

```svelte
<TextField
  label="Email"
  type="email"
  description="We'll never share it."
  onValueChange={(v) => (email = v)}
/>
```

Themeable via `--ds-field-*`.
