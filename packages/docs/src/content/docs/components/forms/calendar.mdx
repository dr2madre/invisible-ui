A WAI-ARIA date grid with keyboard navigation, selection, appointment dots and
per-day prices. Switch between month, two-month, week, three-day, day and year
views.

### Import

<ImportSnippet component="calendar" />

In Elements, names come from `Intl`. Events and prices are properties:

```html
<ds-calendar value="2026-06-15" views="month week day"></ds-calendar>
<script type="module">
  const calendar = document.querySelector("ds-calendar");
  calendar.events = [{ date: "2026-06-18", label: "Review", tone: "warning" }];
  calendar.addEventListener("change", (event) => console.log(event.detail.value));
</script>
```

### Accessibility

- `role="grid"` of day buttons with roving tabindex; arrows move by day/week,
  Home/End to the week edges, PageUp/PageDown by month (Shift = year),
  Enter/Space selects.
- In right-to-left text ArrowLeft moves to the next day and ArrowRight to the
  previous one, and the previous and next arrows are mirrored.
- The period title is announced (`aria-live`); out-of-range days are
  `aria-disabled`; today is `aria-current="date"`.

### First day of the week

Without `weekStartsOn`, every adapter starts the week on the locale's first
day from CLDR week data, read from the language and the region: Sunday for
`en-US`, Monday for `it-IT` and `en-GB`, Saturday for `ar-EG`. The locale is
the calendar's `locale`, else the
[Locale Provider](/invisible-ui/components/localization/locale-provider/)'s,
else the page's `lang`, else the international default, which starts on
Monday (see
[Default locale](/invisible-ui/components/localization/locale-provider/#default-locale)).
The browser's own language never decides. Set `weekStartsOn` (0 = Sunday … 6
= Saturday) to choose the day yourself.

### Example

```svelte
<Calendar
  value="2026-06-15"
  views={["month", "week", "day"]}
  events={[{ date: "2026-06-18", label: "Review", tone: "warning" }]}
  prices={{ "2026-06-12": "€120" }}
/>
```

In React, `onValueChange` reports a pick, `mode="range"` reports both ends
through `onRangeChange`, and `renderDay` replaces a day's content:

```tsx
<Calendar value={day} views={["month", "week"]} events={events} onValueChange={setDay} />
```

Themeable via `--ds-calendar-*`.
