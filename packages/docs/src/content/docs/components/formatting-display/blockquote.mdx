A `<blockquote>` for quoted prose, with optional attribution.

### Import

<ImportSnippet component="blockquote" />

In Elements:

```html
<ds-blockquote cite="Leonardo da Vinci">
  Simplicity is the ultimate sophistication.
</ds-blockquote>
```

### Props

<PropsTable component="blockquote" />

The quote is the children; `cite` takes plain text or a snippet.

### Example

```svelte
<Blockquote cite="Grace Hopper">We've always done it this way.</Blockquote>
```

In React, `cite` takes text or markup:

```tsx
<Blockquote cite="Grace Hopper">We've always done it this way.</Blockquote>
```

Themeable via `--ds-blockquote-*`.
