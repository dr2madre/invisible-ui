Page navigation with first/last boundaries, sibling pages around the current
page, and ellipses.

### Import

<ImportSnippet component="pagination" />

### Props

<PropsTable component="pagination" />

### Accessibility

- `<nav>` with a labelled list; the current page carries `aria-current="page"`.

### Example

```svelte
<Pagination page={3} pageCount={10} onPageChange={(p) => (page = p)} />
```

With Elements, use attributes for configuration and listen for the bubbling
`change` event. Its detail contains the committed `page`.

```html
<ds-pagination page="3" page-count="10" label="Catalog pages"></ds-pagination>

<script type="module">
  import "@design-system/elements/define";

  const pagination = document.querySelector("ds-pagination");
  pagination.addEventListener("change", (event) => {
    pagination.page = event.detail.page;
  });
</script>
```

Use `previous-label`, `next-label` and `page-label` to localize the control.
The `page-label` value supports the `{page}` placeholder.

In React, the control names come from the provider's catalog
(`pagination.previous`, `pagination.next`, `pagination.page`). When a press
disables Previous or Next, focus moves to the page that is now current:

```tsx
<Pagination page={page} pageCount={10} onPageChange={setPage} />
```

Themeable via `--ds-pagination-*`.
