A WAI-ARIA tabs widget: a tablist linked to panels, with arrow navigation.

### Import

<ImportSnippet component="tabs" />

### Props

<PropsTable component="tabs" />

### Accessibility

- WAI-ARIA tabs pattern: roving tabindex, arrow/Home/End navigation, automatic or manual activation.
- Each panel is correctly wired to its tab (`aria-labelledby` / `role="tabpanel"`), whether it holds text `content` or custom markup.

### Example

```svelte
<Tabs
  label="Settings"
  value="account"
  items={[
    { value: "account", label: "Account", content: "Account settings." },
    { value: "password", label: "Password", content: "Password settings." },
  ]}
/>
```

In Elements, assign the item list as a property. Selection is reflected by the
`value` attribute and reported through the bubbling `change` event:

```html
<ds-tabs label="Catalog sections"></ds-tabs>

<script type="module">
  const tabs = document.querySelector("ds-tabs");
  tabs.items = [
    { value: "tables", label: "Tables", count: 11, content: "Table list" },
    { value: "columns", label: "Columns", count: 42, content: "Column list" },
  ];
  tabs.addEventListener("change", ({ detail }) => {
    console.log(detail.value);
  });
</script>
```

In React, `content` takes any markup, and a count is read as part of the tab's
name while the badge stays hidden from assistive technology:

```tsx
<Tabs
  label="Catalog sections"
  value={section}
  onValueChange={setSection}
  items={[
    { value: "tables", label: "Tables", count: 11, content: <TableList /> },
    { value: "columns", label: "Columns", count: 42, content: <ColumnList /> },
  ]}
/>
```

### Rich panels

For anything beyond text, use the `panel` snippet: it renders once per tab
with `{ item }`, so you put whatever you want in the (correctly wired) panel and
switch on `item.value`.

```svelte
<Tabs label="Inbox" value="all" items={[{ value: "all", label: "All" }, { value: "news", label: "News" }]}>
  {#snippet panel({ item })}
    {#if item.value === "all"}
      <MyList items={everything} />
    {:else if item.value === "news"}
      <MyList items={news} />
    {/if}
  {/snippet}
</Tabs>
```

In Elements, set `renderPanel` to return a DOM node. Strings are always treated
as text rather than parsed as HTML:

```js
tabs.renderPanel = (item) => {
  const panel = document.createElement("section");
  panel.append(item.value === "tables" ? tableView : columnView);
  return panel;
};
```

In React, `renderPanel` renders a panel from its item:

```tsx
<Tabs label="Inbox" items={folders} renderPanel={(item) => <MyList folder={item.value} />} />
```

### Composed tabs

When the strip belongs in a header and the panels further down, write the parts
as markup. In Elements, `<ds-tabs>` is the root that holds the state; inside it,
anywhere, go a `<ds-tab-list>` of `<ds-tab value>` elements and one
`<ds-tab-panel value>` per tab. The tabs wire every part (roles, the links
between tab and panel, which one is visible, the keyboard), so a button placed
beside the strip lines up with the tabs rather than with the panel. The
`items` form above is the shortcut for the simple case.

```html
<ds-tabs value="form">
  <header class="editor-header">
    <ds-tab-list label="Editor">
      <ds-tab value="form">Form</ds-tab>
      <ds-tab value="preview">Preview <ds-count count="3"></ds-count></ds-tab>
    </ds-tab-list>
    <ds-button variant="ghost">Close</ds-button>
  </header>

  <ds-tab-panel value="form">…</ds-tab-panel>
  <ds-tab-panel value="preview">…</ds-tab-panel>
</ds-tabs>
```

In React, the composed form is the `useTabs` hook: its prop getters wire the
same roles, links, visibility and keys onto markup of your own, wherever it
sits.

```tsx
const { api } = useTabs({ items: [{ value: "form" }, { value: "preview" }] });

<header className="editor-header">
  <div {...api.rootProps} className="tabs__list" aria-label="Editor">
    <button {...api.getTabProps("form")} className="tabs__tab">Form</button>
    <button {...api.getTabProps("preview")} className="tabs__tab">Preview</button>
  </div>
  <Button variant="ghost">Close</Button>
</header>
<div {...api.getPanelProps("form")} className="tabs__panel">…</div>
<div {...api.getPanelProps("preview")} className="tabs__panel">…</div>
```

Themeable via `--ds-tabs-*`.
