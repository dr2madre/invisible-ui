A row of overlapping avatars with a "+N" overflow chip when there are more
people than `max`.

### Import

<ImportSnippet component="avatar-group" />

In Elements, assign the people as a property:

```html
<ds-avatar-group label="Project team" max="3"></ds-avatar-group>

<script type="module">
  document.querySelector("ds-avatar-group").items = [
    { name: "Ada Lovelace" },
    { name: "Grace Hopper" },
    { name: "Alan Turing" },
    { name: "Katherine Johnson" },
  ];
</script>
```

### Props

<PropsTable component="avatar-group" />

The image `src` is rendered as given: pass only URLs you trust or have
sanitized. See [Security](/invisible-ui/api/#security).

### Accessibility

- The group is a labelled list; each avatar exposes its `name` (or `alt`), and
  the overflow chip announces the remaining count.

### Example

```svelte
<AvatarGroup
  label="Project team"
  items={[{ name: "Ada Lovelace" }, { name: "Grace Hopper" }]}
/>
```

In React:

```tsx
<AvatarGroup
  label="Project team"
  max={3}
  items={[{ name: "Ada Lovelace", color: "rebeccapurple" }, { name: "Grace Hopper" }]}
/>
```

Themeable via `--ds-avatar-*`.
