A fixed, stacking landmark that renders a notifier's queue of
[Notifications](/invisible-ui/components/feedback/notification/).

Pick the `placement` by attention, not by habit: central placements
(`bottom-center`, `top-center`) for outcomes of the user's own actions;
peripheral corners (`top-end`, `bottom-end`) only for background information —
they are exactly where the user may not be looking.

### Import

<ImportSnippet component="notification-region" helpers={["createNotifier"]} />

In Elements, the region element owns the queue: there is no separate
notifier. `show()` and the status shorthands return the id that `update()` and
`dismiss()` take, and the element sends a bubbling `dismiss` event with
`detail.id` and `detail.reason`:

```html
<ds-notification-region placement="bottom-center"></ds-notification-region>

<script type="module">
  const region = document.querySelector("ds-notification-region");
  const id = region.info("Saving…", { closable: false });
  region.update(id, { status: "success", title: "Saved", closable: true, duration: 5000 });
</script>
```

### Interaction

- **Swipe to dismiss** (`swipeable`, on by default): drag a notification
  horizontally past a short threshold — or flick it — to dismiss; a smaller
  drag snaps back. It is a pointer enhancement, so the close button and
  auto-dismiss stay the accessible paths (keyboard and assistive tech are
  never left without a way out). Vertical scroll is preserved.
- **Hovering or focusing anywhere in the stack pauses every countdown** (not
  only the notification under the pointer), so a burst can be read and acted on
  without any of them expiring (WCAG 2.2.1).

### Accessibility

- An accessible landmark: `role="region"` with a label; each Notification
  inside is its own live region. Mounting more than one region on a page
  means giving each its own `label`: two landmarks with the same name are
  the same entry twice in the landmark list.
- Notifications enter/leave with a fly/fade transition and the stack reflows
  via FLIP, disabled under reduced motion.

### Example

```svelte
<script>
  const notifier = createNotifier();
</script>

<NotificationRegion {notifier} placement="bottom-center" />
<Button onpress={() => notifier.show({ status: "success", title: "Saved" })}>
  Save
</Button>
```

Themeable via `--ds-notice-*` and `--ds-elevation-overlay`.
