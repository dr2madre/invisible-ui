A small status chip: a colored label with optional icons, removable, and able
to host a [Count](/invisible-ui/components/feedback/count/).

### Import

<ImportSnippet component="tag" />

### Props

<PropsTable component="tag" />

The children are the label; the `icon` snippet holds a leading icon and the
`trailing` snippet a trailing one.

### Example

```svelte
<Tag status="success" variant="solid">Published</Tag>
<Tag status="info" removable onRemove={() => {}}>Filter</Tag>
<Tag status="danger">
  {#snippet icon()}<Icon><!-- … --></Icon>{/snippet}
  Blocked
</Tag>
```

Elements uses the same light-DOM regions and reports removal without deleting
itself, so the application remains the source of truth:

```html
<ds-tag status="success" removable remove-label="Remove status">Published</ds-tag>

<script type="module">
  document.querySelector("ds-tag").addEventListener("remove", removeStatus);
</script>
```

Themeable via `--ds-tag-*`.
