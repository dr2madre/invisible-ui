After 0.1.0-alpha.1, every public CSS custom property of Invisible UI
starts with `--iui-` instead of `--ds-`. This is a breaking change:
the `--ds-*` names are removed and no fallback reads them, so an override that
still uses them has no effect.

Only the prefix changes. The rest of each name, every value, every alias between
tokens and both themes stay the same. Class names, `<ds-*>` element tags,
package names and component behaviour do not change.

## Update an override

Replace `--ds-` with `--iui-` at the start of each custom property you set or
read:

```css
/* 0.1.0-alpha.1 */
:root {
  --ds-components-button-radius: 0;
}

/* now */
:root {
  --iui-components-button-radius: 0;
}
```

The same applies to custom properties set from code, for example
`element.style.setProperty("--iui-avatar-bg", color)`.

A search for `--ds-` in your stylesheets, templates and scripts finds every
place to change. Custom properties that start with `--_` are internal to the
components and are not part of this change.

## All names

The list is also in the repository as `packages/tokens/migration-iui.json`.
**Token** names are defined by `tokens.css`; **component** names are the
per-component knobs described in
[Component tokens](/invisible-ui/presentation/component-tokens/).
