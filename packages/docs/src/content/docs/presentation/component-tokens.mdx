This inventory lists custom properties read by components. Some are canonical
`components.<name>` tokens from [the token model](/invisible-ui/presentation/tokens/).
Others are CSS-only knobs, such as `--ds-field-gap` and `--ds-dialog-max-width`.

Two things make this tier different from the
[token catalog](/invisible-ui/presentation/token-catalog/):

- **Their ownership differs.** The theme stylesheet defines canonical tokens,
  including `--ds-components-button-radius`. A CSS-only knob can instead use
  a fallback where a component reads it, for example `--ds-field-gap`.
  Set either kind of custom property on a scope you own to override it.
- **Many knobs follow a role.** When the fallback chains through a semantic
  token, retheming the role restyles the knob for free, and the knob exists
  only for the one-off case. Set the role first; reach for the knob when one
  component must differ from its class.

Everything below is generated from the component sources — stylesheets,
markup and render code alike — so the list and the code move together. The whole tier is
**alpha**: names can still change before 1.0.
